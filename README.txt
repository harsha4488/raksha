SHREE RAKSHA — ROMANTIC WEBSITE

Files:
- index.html: the complete responsive website
- images/: your supplied photos and romantic collage

Preview:
Open index.html in a web browser. Keep the images folder beside index.html.

Publish online:
1. Upload the entire shree_raksha_website folder to a GitHub repository.
2. On Render, create a new Static Site and connect that repository.
3. Set Build Command to blank and Publish Directory to ".".
4. Deploy.

You can change the note and headings by editing index.html. Replace/add photos in images and update the matching image paths in index.html.
